## ransomeware

It is a simple malware which encryt all the files in the given directory and only a key is required for decrypt them. \
(*Note*: made only for eductional purposes. )

You just have run the following commands in the terminal:

### Linux

```bash
# for encryption
python3 encrypt.py

# for decryption
python3 decrypt.py
```

### Windows

```bash
# for encryption
python encrypt.py

# for decryption
python decrypt.py
```
